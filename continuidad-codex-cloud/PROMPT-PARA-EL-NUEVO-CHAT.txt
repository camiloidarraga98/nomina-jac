PREPARA Y COMPRUEBA EL ENTORNO
1. Comprueba repositorio, rama, commit, sistema y Node.js 24 LTS. No presupongas que heredaste las conexiones o credenciales de otro chat.
2. Instala con npm ci --no-audit --no-fund y el lockfile existente. No uses npm update ni borres el lockfile. Si aparece el fallo heredado de dependencias opcionales WASI, diagnostícalo; cualquier reparación debe ser mínima, conservar las versiones existentes y quedar documentada.
3. Ejecuta node scripts/prepare-local.mjs para generar claves NUEVAS de desarrollo. No suministres PAYROLL_AUTH_KEY o PAYROLL_MAIL_KEY reales al entorno de pruebas.
4. Para preparar D1 desechable, usa exclusivamente:
   npx --no-install wrangler d1 migrations apply site-creator-d1 --local --config work/local/wrangler.json
   Ese nombre es heredado y corresponde solo al entorno local; nunca uses --remote para preparar pruebas. No sustituyas datos reales por localhost.
5. Ejecuta:
   npx --no-install tsc --noEmit
   node --test tests/payroll.test.mjs tests/payroll-auth.test.mjs tests/payroll-mail.test.mjs tests/cloudflare-deployment.test.mjs
   npm run build
6. Ejecuta también las pruebas específicas indicadas en AGENTS.md para los flujos que cambien. Reutiliza resultados cuando sus entradas no hayan cambiado; no hagas comprobaciones ajenas al cambio.
